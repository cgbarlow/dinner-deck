# Design canvas source

These `.dc.html` files are the artboards from the Claude design canvas where the mockups were drawn. They need the canvas runtime (`support.js`) to render, so they will not open on their own. Use `../index.html` to look at the mockup.

- `Main.dc.html` is the scoring matrix for all 14 Iris collections.
- The other file is this concept's mockup.
